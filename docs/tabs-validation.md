# Tabs contract and acceptance

Pinned Kumo `3fd5b648df578cb1ba214dedd30f475009f6a668` Tabs source, complete tests, documentation and demos were inspected alongside installed Base0.7.0 Tab/TabList. The source supports segmented/underline, base/sm and horizontal navigation; deprecated MenuBar is excluded. Source styling constants describe older geometry: this slice follows current class recipes (36/26px segmented,30/26px underline,14/12px text), subject to remaining browser measurement below.

| Contract | Native core checkpoint |
| --- | --- |
| Identity/content | Typed `TabItem<T>`, stable IDs and unique values; complete readable names, optional decorative content factory. Retain child entities outside rendering and capture owners weakly. |
| Ownership | Caller retains one `Entity<TabsState<T>>` per mounted list. Uncontrolled state applies user changes; controlled state emits `TabsEvent<T>` proposals and waits for silent `set_selected` acceptance. Modes are chosen at construction. No second owner value is maintained in uncontrolled mode. |
| Activation | Base Tab supplies pointer, Enter/Space and accessibility click. Current availability/value are read at activation, repeated selection emits nothing. Pointer activation focuses its tab before keyboard continuation. |
| Navigation | Left/Right wrap and skip disabled; Home/End choose first/last enabled. Default manual activation separates focus from selection; `activate_on_focus(true)` proposes on navigation. Modified keys and vertical arrows are left to the host. |
| Focus | Retained per-ID handles survive reorder; one enabled tab stop per list, selected/focused/first fallback. Removed or newly unavailable focused items transfer to the remaining selected/first enabled item, or traverse forward if empty. Programmatic collection/value updates emit no user proposal. |
| Availability | Per-item/group disabled gates all input, removes traversal entry and authors disabled on Base's actual tab node. Existing focus remains until traversal or collection replacement; no focus theft on a group availability update. |
| Presentation | Both variants/sizes use Kumo theme tokens, moving selected surface/underline and keyboard ring. Border/ring paint does not move labels when focus/selection changes. Native horizontal overflow and nearest focused-tab reveal work. |
| Meaning | Base TabList and Tab roles, names, selected state and set position/size. Native AT-SPI observes selection, disabled availability and focus. Speech is a separate gate. |
| Panels/orientation | Source Kumo exports no panel/mount API or orientation prop; panels and focus inside content are consumer-owned, vertical orientation is N/A for this source wrapper. No inferred TabPanel API is exported. |
| Web replacement/links | DOM `render`, `nativeButton`, CSS classes and browser navigation are not copied as Rust flags. Decorative content is available; a complete native replacement/navigation composition contract remains open. |

The focused example imports the gallery's actual Tabs section. [Native evidence and reproduction](evidence/tabs/README.md) covers Light/Dark1040/520 and real pointer, keyboard and AT-SPI paths. Seven rendered regressions cover manual/automatic selection, rejected and silent accepted controlled proposals, disabled skipping, host traversal, repeated independent instances, reorder, removal and empty-list focus. Event subscriptions are checked after the GPUI update flush, rather than assuming synchronous `cx.emit` delivery. Base's internal headless observation is installed after its caller-supplied focus binding, so tests inspect the retained handle's actual window focus; native AT-SPI supplies the independent exported-focus check.

Skeptical review caught missing TabStop registration on explicitly tracked handles: setting only an element's `tab_stop` does not alter its supplied FocusHandle in this GPUI revision. The wrapper now passes configured clones of retained handles, and the tests verify traversal **into** the list as well as exit. No vendor change was necessary. Per-list nested tab groups reordered unrelated sibling Buttons in the selected GPUI traversal model; they were removed and repeated-list/native traversal now exercise the shared host ordering.

**Open under #32:** native replacement/link composition, control opacity transitions (source150ms), indicator enter/exit scale/opacity, full-gallery integration review and platform speech gates. Arbitrary rich descendant clipping and arbitrary transparent/gradient parent masking remain unsupported. Working family coverage remains28/43; this milestone does not add another family or complete full fidelity.

## Overflow/motion continuation contract

Pinned browser measurements in this continuation confirm36/26px segmented tracks with32/22px tabs,30/26px underline lists with24/20px tabs, small tab4px radii and base underline4px radius. Source segmented controls are40/32px wide,24/20px inner targets,14px chevrons and a4px outer inset; only edges with remaining scroll are operable and tab stops. Underline has no edge buttons.

Implement source page-by-whole-tab scroll distance, pointer drag threshold greater than3px with release activation suppressed, nearest focused-tab reveal, dynamic collection/resize edge visibility, localized scroll names,200ms moving/resizing selected indicator and reduced-motion settling. Retain pointer/action focus and recover when a focused edge action disappears after scrolling, resize or owner removal. Keep weak event captures and measured layout derived from the single authoritative collection. Pointer drag cancels pending smooth scroll; keyboard reveal wins over scroll animation. Validate controlled rejection leaves the indicator on the accepted value, rapid reversal starts from painted intermediate position, shrinking collections remove edge controls without trapping focus, and repeated instances/drag cancellation stay independent. Native smooth-scroll duration is an explicit200ms adaptation to browser-owned `behavior:smooth` timing.

## Implemented overflow and motion checkpoint

Segmented overflow actions use Base Button, localized `TabsLabels`,40/32px targets and source page-by-whole-tab distance. Native200ms smooth scrolling is an adaptation to browser-owned smooth timing. Pointer dragging starts only beyond3px, suppresses release activation, and cancels scrolling; keyboard reveal also cancels scrolling. Mount-scoped cleanup clears transient drag/animation state even when callers retain the entity. The scroll clock is a separate child so starting scrolling preserves tab/accessibility node identity. Overlapping buttons occlude underlying tabs; pointer activation keeps focus on the action before Space/Enter.

Selected indicators move and resize over200ms with source cubic-bezier(.4,0,.2,1), reverse from their last painted bounds, and settle immediately for reduced motion. Segmented indicators have source shadow-sm and an outside1px line ring; underline tabs now measure24/20px and small/underline radii4px. Edge fades use48px ramps; `.fade_surface(color)` supports a caller's opaque parent surface. GPUI has no equivalent arbitrary descendant alpha mask in this implementation; transparent/gradient parent parity remains open.

Hidden native edge controls recover focus to a visible enabled edge tab, or the selected/first tab when overflow disappears; empty lists traverse forward. Source hidden DOM controls can retain focus, so this recovery is an intentional native adaptation. Collection/configuration changes invalidate measured action geometry until layout refreshes. Seven rendered tests cover stale owner actions, resize/removal, actual drag input/unmount, painted indicator interpolation/reversal and reduced-motion quiescence in addition to core contracts.
