## Nested overlay and mount lifetime checkpoint — 2026-10-03

Select `.parent(&PopoverClose)` registers a weak bounds/dismissal capability with Popover. Pointer selection beyond the parent surface stays inside the composition; parent dismissal closes descendants, while open Select Escape closes only Select and closed Select Escape reaches the parent. Open/value/bounds remain authoritative in Select; the parent owns only weak capabilities. Parent release, reparenting and omitted association detach cleanup without stealing outside focus.

Independent review reproduced an unmount leak when the application retained SelectState after removing the widget: stale bounds shielded former popup space from parent outside dismissal. Fixed using installed GPUI mount-scoped persistent element state keyed by identity/type. The state owns only a weak mount; teardown defers cleanup past frame borrowing, closes/releases the popup and detaches the parent, while a live newer mount protects remounts. Removed focused handles blur without restoring removed controls. Retained value survives remount; unmounted controls reject reopening/activation. No per-frame entity/subscription or duplicate open state.
