## Core implementation checkpoint — 2026-10-03

The core checkpoint supplies typed single/multiple values, stable option IDs, pure/custom logical equality, rich decorative option factories, local/controlled selection, programmatic setters, four sizes, placeholder/loading, optional visible Field label/helper/error precedence, native read-only browsing, disabled pointer/key gating, retained open/highlight/scroll/focus and deferred Base lifecycle. Constructor establishes selection mode; changing single/multiple mode requires a fresh state rather than silently discarding values. Mount each retained state once in one window. Subscribe to SelectEvent to accept a controlled value proposal; updates run outside the state borrow and setters emit no value proposals. Equivalent logical selections preserve the owner payload and do not emit.

Kumo button recipes govern rest/hover/open/control fill, shadow-xs, disabled layering and foreground, source caret-up-down12/14/16/18, regular14px Check, inset keyboard rings and error focus treatment. Source Phosphor React2.1.10 glyph path and MIT license are retained. A source-sized list viewport intentionally crops partially scrolled rows at its straight edge; highlight fills and inset rings stay within supported rounded boundaries.
