Native adaptation decisions before coding: logical `T: Clone + PartialEq` values and explicit stable option IDs replace JavaScript reference/key inference; custom comparator supports richer values. Retained entity exposes owner setters and a controlled proposal policy, avoiding a second external value mirror. Rich content factories create presentation only; consumer entities are retained outside rendering. Plain unlabelled option child text avoids duplicate accessible names. Base Select root is the painted semantic trigger; pointer handler can live on its unlabelled child without adding a duplicate Button role. Source custom trigger/selected-item overlay alignment/portal containers and native active/controlled relationships require explicit verified adaptation rather than invented Base parts.
