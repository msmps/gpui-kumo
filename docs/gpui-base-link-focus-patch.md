# Base0.7.0 retained Link focus correction

Published Base crate checksum64bb52b29a8dcdc8d3f595b8b0839c076f237572ab601ba4577d3da8ae085728. Kit/Base remains0.7.0 and the GPUI family remains0.3.7. The already vendored published `gpui-base-0.7.0` is modified only in `src/link.rs` for this correction; previous Input/editor/button behavior patches and provenance remain unchanged. Upstream Apache2.0 source/license are retained.

The published Link implements InteractiveElement, so `track_focus` compiles and initially stores the supplied handle in its inner Div. Render then creates its own keyed focus handle and tracks it instead. Native Toolbar navigation focuses the retained caller handle, but that handle is absent from the rendered dispatch/tab registry: the next arrow stops at the link and Tab restarts at the first external control. Real rendered regressions reproduced both failures; Button already provides a correct retained-handle hook.

Add an optional provided handle, initializedNone; an inherent `track_focus` stores its clone, and `focus_handle` uses it or retains the existing keyed default. Activation, open strategy, roles, disabled behavior, style, editing and platform adapters are unchanged. The inherent method intentionally takes precedence over the previously ineffective trait method. No second native activation engine or synthetic wrapper focus node is introduced.

Regression coverage: Toolbar's rendered pointer-modifier/navigation test proves actual Base pointer focus matches the supplied retained target and uses the current destination once. Roving navigation checks arrows across a Link, one Tab exit and last-focused reentry; vertical/nonloop/narrow reveal and reorder/removal exercise the same boundary. Existing Link and Breadcrumbs workspace regressions run against this correction. Native AT-SPI independently queries actual focused Link nodes; speech remains a separate gate.

Design-system maintainers own this patch. Remove it after adopting a compatible Base release that preserves supplied Link focus during rendering, then rerun Link/Breadcrumbs/Toolbar/host traversal and native accessibility tests. Do not grow this patch into a navigation or styling rewrite. Cargo patches do not propagate from dependency manifests: consumers must preserve this exact vendored Base under their own root `[patch.crates-io]` (`gpui-base = { path = "vendor/gpui-base-0.7.0" }`), alongside this project's existing GPUI/Base/AccessKit overrides. Unpatched0.7.0 does not supply the required retained-link hook.
