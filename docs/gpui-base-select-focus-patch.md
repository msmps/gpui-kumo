# GPUI Base Select confirmation focus patch

Pinned Base0.7.0 remains unchanged in version and dependencies. Alongside the documented [Textarea growth repair](gpui-base-textarea-growth-patch.md), the vendor changes `src/select.rs`: open-state confirmation no longer unconditionally focuses popup content after the consumer callback. The registry implementation overwrote the callback’s restored trigger focus or deliberately chosen outside focus after closing; this also left focus targeting content removed by the following render.

Closed-state Enter still calls the opening callback and transfers focus to content. Open-state Enter calls the confirmation callback, which owns selection, closing and the resulting focus. Navigation, disabled gating, Escape and accessibility dismissal are unchanged. No new Select presentation or collection API is claimed.

`crates/gpui-kumo/src/select_base_tests.rs` reproduces this through the actual Base root and native rendered keyboard path: initial opening focuses content, confirmation fires once, and closing retains the chosen trigger or outside focus through rerender. It fails against original Base (`/tmp/select-base-before.log`) and passes the patch. Independent review found no blocker. Full gate:135 workspace tests/nine doctests, formatting, warning-denied all-target/all-feature Clippy and workspace all-target/all-feature build pass (`/tmp/select-base-final-{test,fmt,clippy,build}.log`). The pre-existing GPUI profiler deprecation remains visible. Upstream Base’s own suite was not run: its non-workspace dev-dependency setup is unavailable in this checkout. Browser comparison and platform accessibility remain separate gates.

Downstream Cargo roots must apply the Base and GPUI overrides shown in the growth-patch document; dependency-level patches do not propagate. Vendor inventory now differs in exactly three source files (the two intrinsic-growth files plus Select). Remove this correction only when a pinned upstream release passes the consumer focus regression. Tracker [#27](https://github.com/msmps/gpui-kumo/issues/27) remains in progress for the actual Kumo Select component.
